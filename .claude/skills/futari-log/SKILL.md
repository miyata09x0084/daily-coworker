# ふたりログ

`webapp/`（ふたりログ）に貯まっている実データを読み、ふりかえり・次の一手の提案・
記録の追加を行う。**会話の記憶から答えない。必ず実データを読む。**

## 前提

- データの実体: `data/futari-log/db.json`（git 管理外の個人データ）
- 集計・警告・カード文面はすべてアプリ側（`webapp/server/insights.js` / `handoff.js`）が出す。
  ここで数え直さない。数える場所を増やすと、画面とAIの言うことがずれる。

## 1. データの取り方

まずサーバーが動いているか確かめる。

```bash
curl -s --max-time 2 http://127.0.0.1:4173/api/insights > /dev/null && echo up || echo down
```

- **up** → API を使う
  - ふりかえり: `curl -s "http://127.0.0.1:4173/api/review?format=markdown"`
  - 集計: `curl -s http://127.0.0.1:4173/api/insights`
  - 渡すカード: `curl -s "http://127.0.0.1:4173/api/handoff?nextTalkDate=YYYY-MM-DD"`
- **down** → 起動してよいか一言ことわってから `cd webapp && npm start`（バックグラウンド）。
  起動を断られた場合のみ `data/futari-log/db.json` を直接読む。その場合は
  「警告と集計はアプリを起動していないため自分で数えた概算」と明示する。

データが空（記録0件）なら、分析を作らずにそう言う。ないものから傾向は出ない。

## 2. ふりかえりを求められたとき

1. `/api/review?format=markdown` の出力をそのまま土台にする（数字を書き換えない）
2. そのうえで、アプリが出せない**解釈**だけを足す:
   - やりとりの本文（`summary` / `note`）を読んで気づいたこと
   - 調子が落ちた時期と、その前後で何を頼んでいたかの対応
   - 同じ用件が何度も出てきていないか
3. 最後に「次の一手」を **1つだけ** 提案する。複数出すと実行されない。

### 断定しない線引き

- `techniqueEffect.rows` の `enough: false` の行は**根拠として使わない**。
  件数が足りないことをそのまま伝える。
- 調子（condition）は記録者から見た印象であって、診断でも測定値でもない。
  「調子が悪い」を本人の状態の断定として書かない。
- 医療・福祉の判断（服薬、診断、支援区分など）には踏み込まない。
  気になる兆候は「支援員や主治医に相談する材料」として出す。

## 3. 記録の追加を頼まれたとき

会話から埋められる項目だけを埋め、**推測で埋めない**。
特に `condition`（調子）と `understanding`（理解確認）は、
ユーザーが言っていないなら入れない（既定のまま送る）。

```bash
curl -s -X POST http://127.0.0.1:4173/api/interactions \
  -H 'Content-Type: application/json' \
  -d '{
    "summary": "（会話から取った本文）",
    "channel": "face",
    "commitments": [
      { "title": "（決まったこと）", "owner": "him", "due": "YYYY-MM-DD" }
    ]
  }'
```

- `owner`: `him` / `me` / `both`
- 期限が会話に出ていなければ `due` を入れず、**「いつまでにするか決めますか？」と聞く**。
  期限のない約束は落ちる、というのがこのアプリの前提。
- 送ったあと、作成された内容をユーザーに読み上げて確認を取る。

## 4. 渡すカードを頼まれたとき

`/api/handoff` の `text` を**そのまま**提示する。整えたり要約したりしない。
言い回しは、一度に渡す量と語彙を意図して抑えてある（本人の言語理解に合わせた設計）。

`note` に「載せきれなかった件数」が入っていたら、それも併せて伝える。

## 出力の形

- 数字は API の出力をそのまま使う
- 提案は1つ
- 200〜400字程度。長いふりかえりは読まれない
